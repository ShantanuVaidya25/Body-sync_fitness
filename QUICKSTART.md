# 🚀 QUICK START GUIDE

## Installation (5 Minutes)

### Step 1: Extract Files
Extract the `solo_leveling_fitness` folder to your desired location.

### Step 2: Install Python
If you don't have Python installed:
- **Windows**: Download from https://www.python.org/downloads/
- **Mac/Linux**: Usually pre-installed, or use `brew install python3`

### Step 3: Run the Application

#### On Windows:
Double-click `start.bat`

#### On Mac/Linux:
```bash
./start.sh
```

#### Manual Start (Any System):
```bash
pip install -r requirements.txt
cd backend
python app.py
```

### Step 4: Open Browser
Go to: http://localhost:5000

## Troubleshooting

**Server won't start:**
- Check if port 5000 is available
- Try `python app.py --port 5001`

**Can't login:**
- Clear browser cache
- Check username/password

**No quest generated:**
- Complete profile setup first
- Restart server
